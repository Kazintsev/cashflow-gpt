# cashflow-gpt — Финансы

Система личного финансового учёта на PostgreSQL / Supabase с управлением через чат. Помогает записывать расходы и доходы, учитывать долги, планировать платежи и понимать, сколько денег свободно до следующего поступления.

**Редакция документации: 7 сентября 2026 года.** Описана фактически обследованная схема `public`: 19 таблиц, 4 представления, 76 сигнатур функций и 53 пользовательских триггера. Справочники сформированы из системного каталога; ключевые правила дополнительно сверены с телами функций.

Это пакет документации к существующей реализации. Миграции, установочный скрипт, демонстрационная база и настроенное подключение ChatGPT в пакет пока не входят. Полное развёртывание из GitHub ещё не проверено. Оставшиеся работы перечислены в [подготовке выпуска](docs/release.md).

## Что умеет описанная реализация

- Учитывает операции между счетами и остатки на конкретный момент времени.
- Разделяет бюджетные расходы, расходы вне бюджета и перемещения денег.
- Хранит правила повторяющихся платежей и материализует события календаря.
- Различает обеспечение будущего платежа и фактическое исполнение.
- Учитывает возобновляемый долг кредитной карты и кредит с графиком.
- Возвращает единый оперативный статус и прогноз на выбранную дату.
- Поддерживает разбиение расхода по категориям и хранение данных чека.
- Предоставляет идемпотентную запись команд и проверки согласованности данных.

Наличие таблиц чеков не подтверждает наличие готового OCR, банковского подключения или импорта Excel. Эти интеграции не обследовались и не объявляются готовыми.

## Модель использования

Первая открытая версия предполагает отдельную базу для одного владельца или одного общего финансового контура. Многопользовательская изоляция в обследованной схеме не реализована. Подробности и требования к доступу — в [архитектуре](docs/architecture.md).

Все суммы и названия счетов в учебных сценариях вымышлены. Документация не содержит строк из личного журнала операций, секретов подключения или идентификатора рабочей базы.

Лицензия будущего репозитория ещё не выбрана; этот пакет не является опубликованным open-source-релизом.
